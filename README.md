# Order Houses of Lower Saxony

Prototype map of the houses of the Hospitallers, Templars, Teutonic Order and Carmelites in Lower Saxony,
built from the Lower Saxony sheet of the Niedersächsisches Klosterbuch data (sheet 13).

- `index.html`: entry page
- `map.html`: the map
- `houses.html`: index of all houses
- `house.html`: one house's full record (`house.html#H-043`)

The pages are generated; the data cleaning and the build script live in the `orders-map` repository.
